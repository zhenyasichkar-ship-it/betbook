# Betbook

Учебное Telegram Mini App на Next.js, TypeScript и PostgreSQL. Баланс, ставки и выплаты выражены в виртуальных $. Пополнения реальными деньгами и вывода средств нет.

## Правила

- При первом входе за календарный день сервер начисляет 100 виртуальных $. Новый день начинается в 00:00 по времени Киева. Бонусы за пропущенные дни не накапливаются.
- В каждом раунде человек играет против трёх ботов. Три стартовых раунда выигрывает игрок. С четвёртого раунда его шанс составляет 8% от доли банка. Например, при доле 95% шанс выигрыша составляет 7,6%. Остальная вероятность делится между ботами пропорционально их вкладам.
- Цветные секторы колеса показывают доли банка. Фактический шанс указан отдельно в таблице. Сервер определяет победителя, а колесо показывает результат.
- Выигрыши ботов берутся из сыгранных раундов. Профиль показывает чистый проигрыш (ставки минус выплаты, минимум 0), отдельно от ежедневных бонусов.

## Локальный запуск

1. Установите Node.js 24 и выполните `npm ci`.
2. Создайте `.env.local` по образцу `.env.example`. Укажите `DATABASE_URL` отдельной тестовой PostgreSQL. Для запуска в локальном браузере установите `BETBOOK_LOCAL_DEMO=1`. Эта настройка работает только в режиме разработки на localhost и использует общий тестовый профиль.
3. Выполните `npm run db:migrate` и `npm run dev -- --hostname 127.0.0.1`. Откройте `http://localhost:3000`.

## Vercel и Telegram

1. Создайте бота через `/newbot` в [@BotFather](https://t.me/BotFather). Сохраните токен для переменных окружения Vercel.
2. Импортируйте репозиторий GitHub в [Vercel](https://vercel.com/docs/git). Используйте пресет Next.js, корневую папку репозитория и Node.js 24.
3. Подключите [Neon Postgres через Vercel Marketplace](https://vercel.com/docs/postgres). Задайте `DATABASE_URL` с pooled URL Neon, если интеграция добавила его под другим именем. Для инициализации базы выполните SQL из `db/001_initial.sql` в Neon SQL Editor или запустите `npm run db:migrate` с той же строкой подключения в локальном окружении.
4. Добавьте `TELEGRAM_BOT_TOKEN` в переменные окружения Production. Не добавляйте токен в переменные с префиксом `NEXT_PUBLIC_`, исходники или историю Git. После настройки переменных запустите production deploy.
5. В @BotFather выберите `/mybots → бот → Bot Settings → Configure Mini App → Enable Mini App` и укажите постоянный HTTPS-адрес production-проекта. При желании добавьте ту же ссылку в кнопку чата через `/setmenubutton`. [Настройка Main Mini App](https://core.telegram.org/bots/webapps#launching-the-main-mini-app)
6. Откройте приложение из профиля бота на телефоне. Проверьте стартовый баланс, завершите раунд и откройте приложение снова, чтобы убедиться, что баланс сохранился.

Отдельный процесс для бота не нужен. Telegram открывает Mini App по ссылке, а серверные маршруты Next.js проверяют подпись Telegram и обслуживают игру.
