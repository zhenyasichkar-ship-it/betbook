# Betbook

Навчальний Telegram Mini App на Next.js, TypeScript і PostgreSQL. Баланс, ставки й виплати — у віртуальних доларах. У грі немає платежів та виведення коштів.

## Правила

- Сервер нараховує 100 віртуальних $ при першому вході за день. Новий день починається опівночі за Києвом. Пропущені бонуси не накопичуються.
- Раунди тривають дві хвилини за серверним часом. У кожному грають від 8 до 12 ботів зі змінного складу з 48 учасників. Без ставки гравця відбувається спільний раунд ботів.
- Доступна одна ставка на раунд. Ставка резервується відразу. Після завершення раунду її результат і виплата записуються при наступному підключенні гравця. Бот-раунди відтворюються за номером двохвилинного проміжку, тому не потребують фонової задачі.
- Перші три ставки гравця виграють. Далі шанс дорівнює частці банку, помноженій на коефіцієнт раунду. Після серії програшів коефіцієнт збільшується до встановленої межі. Після стартових ставок математичне очікування для гравця від’ємне. Частка банку та фактичний шанс показані окремо до підтвердження ставки.
- Сектори мають мінімальну ширину для аватарок. Точні частки наведені в таблиці. Профіль показує чистий програш за завершеними раундами без щоденних бонусів.

## Локальний запуск

1. Встановіть Node.js 24 і виконайте `npm ci`.
2. Створіть `.env.local` за зразком `.env.example`. Укажіть `DATABASE_URL` окремої тестової PostgreSQL. Для браузерного запуску встановіть `BETBOOK_LOCAL_DEMO=1`. У режимі розробки на localhost застосунок використає спільний тестовий профіль.
3. Виконайте `npm run db:migrate` і `npm run dev -- --hostname 127.0.0.1`. Відкрийте `http://localhost:3000`.

## Vercel і Telegram

1. Створіть бота через `/newbot` у [@BotFather](https://t.me/BotFather).
2. Імпортуйте репозиторій GitHub у [Vercel](https://vercel.com/docs/git) із пресетом Next.js і Node.js 24.
3. Підключіть [Neon Postgres](https://vercel.com/docs/postgres). Якщо інтеграція додала рядок підключення під іншим іменем, задайте `DATABASE_URL` із pooled URL. Застосуйте SQL-файли з `db/` за порядком номерів у Neon SQL Editor або виконайте `npm run db:migrate` із відповідним рядком підключення.
4. Додайте `TELEGRAM_BOT_TOKEN` як секретну змінну Production і запустіть новий деплой.
5. У @BotFather перейдіть до `/mybots → бот → Bot Settings → Configure Mini App → Enable Mini App` і вкажіть постійну HTTPS-адресу проєкту. [Налаштування Main Mini App](https://core.telegram.org/bots/webapps#launching-the-main-mini-app)
6. Відкрийте застосунок із профілю бота й перевірте баланс та участь у наступному раунді.
